# Admin: Reports

The **budget usage** report shows budget, spend, remaining and utilization per cost center for a selectable period, plus the number of users, keys and requests.

## Period

Choose **From** and **To**. Without a selection the current month applies.

## Drill-down

Click a row to open the details of the cost center: spend and requests per user and, below that, per key.

## Excel export

The export of all cost centers as `.xlsx` and the SAP rebooking follow in **release 2**. The button is therefore still disabled.
