# Admin: Reports

Der Report **Budgetverbrauch** zeigt pro Kostenstelle Budget, Verbrauch, Rest und Auslastung für einen wählbaren Zeitraum, dazu die Anzahl der User, Keys und Requests.

## Zeitraum

Wählen Sie **Von** und **Bis**. Ohne Angabe gilt der aktuelle Monat.

## Drill-down

Ein Klick auf eine Zeile öffnet die Details der Kostenstelle: Verbrauch und Requests pro User und darunter pro Key.

## Excel-Export

Der Export aller Kostenstellen als `.xlsx` und die Umbuchung nach SAP folgen in **Release 2**. Der Button ist deshalb noch deaktiviert.
